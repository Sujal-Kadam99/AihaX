# AihaX — Evidence Model & Cryptographic Integrity

## Evidence Graph & Immutability

AihaX links all security findings to deterministic, verifiable evidence records.

---

## 1. Cryptographic Evidence Hashing (`EvidenceHasher`)

Every finding's core evidence is hashed using SHA-256:

```python
evidence_hash = SHA256(
    vuln_type + affected_url + affected_param + payload + proof_request + proof_response + reason_code
)
```

### Immutability Invariants:
- Once a finding is verified, its `evidence_hash` is computed and stored.
- Any subsequent modification to the payload, request, or response invalidates the hash.
- Verified findings cannot be edited without triggering re-verification.

---

## 2. Evidence Traceability

Each finding maintains structured traceability metadata:
- `evidence_ids`: References to captured evidence payloads.
- `request_ids`: UUIDs of the raw HTTP requests generated by `RequestEngine`.
- `proof_request`: Full HTTP request text with sensitive secrets redacted.
- `proof_response`: Exact HTTP response snippet confirming vulnerability.
