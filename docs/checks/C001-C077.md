# Complete AihaX Vulnerability Catalog (C001–C077)

---

## Category A — Recon / Asset Security (C001–C011)

### C001: Open Port / HTTP Exposure
- **Category**: `RECON` | **Severity**: `INFO` | **CWE**: CWE-319 | **OWASP**: A02:2021-Cryptographic Failures
- **Security Property**: Cleartext HTTP service (port 80) must enforce immediate redirect to TLS/HTTPS.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "port"]`
- **Remediation**: Configure web server to permanently redirect all HTTP traffic to HTTPS via 301/308 redirects.

### C002: Missing Security Headers
- **Category**: `RECON` | **Severity**: `LOW` | **CWE**: CWE-16 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Mandatory HTTP defense-in-depth headers (HSTS, X-Content-Type-Options, X-Frame-Options, CSP) are emitted.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "missing_headers"]`
- **Remediation**: Configure web server to emit modern security headers on all responses.

### C003: Sensitive Files Exposure
- **Category**: `RECON` | **Severity**: `HIGH` | **CWE**: CWE-200 | **OWASP**: A01:2021-Broken Access Control
- **Security Property**: Configuration, backup, and environment files (.env, wp-config.php) must not be web-accessible.
- **Verification Strategy**: `sensitive_file_exposure`
- **Required Evidence**: `["affected_url", "proof_response", "exposed_file_path"]`
- **Remediation**: Block access to dotfiles and configuration files at the web server layer.

### C004: CORS Misconfiguration
- **Category**: `RECON` | **Severity**: `MEDIUM` | **CWE**: CWE-346 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Cross-origin behavior must not reflect arbitrary Origin headers with Access-Control-Allow-Credentials: true.
- **Verification Strategy**: `cors_misconfiguration`
- **Required Evidence**: `["affected_url", "proof_response", "origin_sent", "cors_headers"]`
- **Remediation**: Use an explicit allowlist of trusted origins in Access-Control-Allow-Origin.

### C005: GraphQL Introspection Enabled
- **Category**: `RECON` | **Severity**: `LOW` | **CWE**: CWE-200 | **OWASP**: A01:2021-Broken Access Control
- **Security Property**: GraphQL schema introspection (__schema query) must be disabled in production.
- **Verification Strategy**: `graphql_introspection`
- **Required Evidence**: `["affected_url", "proof_response", "schema_snippet"]`
- **Remediation**: Disable introspection query execution in GraphQL production gateway.

### C006: Directory Listing Enabled
- **Category**: `RECON` | **Severity**: `LOW` | **CWE**: CWE-548 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Web server must not generate automatic index listings for directories.
- **Verification Strategy**: `directory_listing`
- **Required Evidence**: `["affected_url", "proof_response", "directory_path"]`
- **Remediation**: Disable directory browsing (e.g. `Options -Indexes` in Apache, `autoindex off;` in Nginx).

### C007: Open Redirect
- **Category**: `RECON` | **Severity**: `MEDIUM` | **CWE**: CWE-601 | **OWASP**: A01:2021-Broken Access Control
- **Security Property**: User-controlled redirect parameters must not redirect to untrusted external domains.
- **Verification Strategy**: `open_redirect`
- **Required Evidence**: `["affected_url", "proof_response", "redirect_location"]`
- **Remediation**: Validate redirect targets against an explicit allowlist or restrict redirects to relative paths.

### C008: Subdomain Takeover / Dangling DNS
- **Category**: `RECON` | **Severity**: `HIGH` | **CWE**: CWE-404 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: DNS records must not point to unclaimed or deprovisioned cloud service providers (AWS S3, GitHub Pages, Heroku).
- **Verification Strategy**: `subdomain_takeover`
- **Required Evidence**: `["affected_url", "proof_response", "dangling_service", "fingerprint"]`
- **Remediation**: Remove dangling DNS CNAME records or claim the resource name on the cloud provider.

### C009: Exposed Administrative Interface
- **Category**: `RECON` | **Severity**: `MEDIUM` | **CWE**: CWE-200 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Administrative and management consoles (/admin, /wp-admin, /actuator) must not be publicly exposed without network controls.
- **Verification Strategy**: `sensitive_file_exposure`
- **Required Evidence**: `["affected_url", "proof_response", "admin_interface_type"]`
- **Remediation**: Restrict admin consoles using IP allowlisting, VPN access controls, or strong MFA.

### C010: TLS / HTTPS Configuration Weakness
- **Category**: `RECON` | **Severity**: `LOW` | **CWE**: CWE-319 | **OWASP**: A02:2021-Cryptographic Failures
- **Security Property**: HTTPS services must enforce Strict-Transport-Security with adequate max-age (>= 15768000s) and includeSubDomains.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "hsts_header"]`
- **Remediation**: Add `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload` header.

### C011: Technology / Version Exposure
- **Category**: `RECON` | **Severity**: `INFO` | **CWE**: CWE-200 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Web servers should suppress detailed version banners in headers (Server, X-Powered-By).
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "exposed_headers"]`
- **Remediation**: Disable verbose server banners (ServerTokens Prod, server_tokens off) and remove X-Powered-By.

## Category B — Authentication & Session Security (C012–C022)

### C012: Authentication Bypass Indicators
- **Category**: `AUTH` | **Severity**: `HIGH` | **CWE**: CWE-287 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Security Property**: Authorization filters must not be bypassed via path normalization (/..;/) or header overrides (X-Original-URL).
- **Verification Strategy**: `authentication_comparison`
- **Required Evidence**: `["affected_url", "proof_response", "bypass_technique"]`
- **Remediation**: Standardize URL path normalization between edge reverse proxies and application frameworks.

### C013: Weak Session Cookie Configuration
- **Category**: `AUTH` | **Severity**: `LOW` | **CWE**: CWE-614 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Security Property**: Session cookies must be scoped strictly to the origin domain and enforce secure cookie prefixes.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "cookie_header"]`
- **Remediation**: Omit broad Domain attributes and adopt `__Host-` cookie prefixes.

### C014: Missing Secure Cookie Attribute
- **Category**: `AUTH` | **Severity**: `MEDIUM` | **CWE**: CWE-614 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Sensitive session and authentication cookies must always include the Secure flag.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "cookie_header"]`
- **Remediation**: Add the `Secure` attribute to all Set-Cookie directives for sensitive authentication tokens.

### C015: Missing HttpOnly Cookie Attribute
- **Category**: `AUTH` | **Severity**: `MEDIUM` | **CWE**: CWE-1004 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Authentication and session tokens must include the HttpOnly flag to prevent client-side script access.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "cookie_header"]`
- **Remediation**: Set `HttpOnly` on all sensitive cookies in Set-Cookie response headers.

### C016: Missing SameSite Cookie Attribute
- **Category**: `AUTH` | **Severity**: `LOW` | **CWE**: CWE-1275 | **OWASP**: A01:2021-Broken Access Control
- **Security Property**: State-managing cookies must declare SameSite=Lax or SameSite=Strict to defend against CSRF.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "cookie_header"]`
- **Remediation**: Add `SameSite=Lax` or `SameSite=Strict` to all Set-Cookie directives for session tokens.

### C017: Session Fixation Indicators
- **Category**: `AUTH` | **Severity**: `HIGH` | **CWE**: CWE-384 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Security Property**: Applications must regenerate session identifiers upon authentication and reject unauthenticated session adoption.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "fixed_session_token"]`
- **Remediation**: Regenerate session ID (e.g. `session.regenerate_id()`) immediately after successful login.

### C018: Session Invalidation Failure
- **Category**: `AUTH` | **Severity**: `MEDIUM` | **CWE**: CWE-613 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Security Property**: Server-side session state must be destroyed and tokens invalidated immediately upon logout.
- **Verification Strategy**: `authentication_comparison`
- **Required Evidence**: `["affected_url", "proof_response", "replayed_token"]`
- **Remediation**: Invalidate the session on the server-side database/cache upon receiving a logout request.

### C019: Password Policy Weakness Indicators
- **Category**: `AUTH` | **Severity**: `LOW` | **CWE**: CWE-521 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Security Property**: Authentication endpoints must enforce a robust password policy (minimum length >= 8 characters).
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "tested_weak_password"]`
- **Remediation**: Enforce minimum password length (at least 8–12 characters) and reject common passwords.

### C020: JWT Algorithm / Configuration Weakness
- **Category**: `AUTH` | **Severity**: `CRITICAL` | **CWE**: CWE-347 | **OWASP**: A02:2021-Cryptographic Failures
- **Security Property**: JWT tokens must enforce verified cryptographic signatures and reject 'none' or unsigned algorithms.
- **Verification Strategy**: `authentication_comparison`
- **Required Evidence**: `["affected_url", "proof_response", "forged_token"]`
- **Remediation**: Configure JWT libraries to explicitly allow only trusted algorithms (e.g. RS256) and reject `alg: none`.

### C021: JWT Claim Validation Weakness
- **Category**: `AUTH` | **Severity**: `HIGH` | **CWE**: CWE-672 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Security Property**: JWT tokens must strictly validate the 'exp' (expiration) and 'nbf' standard claims.
- **Verification Strategy**: `authentication_comparison`
- **Required Evidence**: `["affected_url", "proof_response", "expired_token"]`
- **Remediation**: Ensure JWT verification libraries validate token expiration (`verify_exp=True`).

### C022: Authentication Rate-Limit Weakness
- **Category**: `AUTH` | **Severity**: `MEDIUM` | **CWE**: CWE-307 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Security Property**: Authentication endpoints must enforce rate limits (returning HTTP 429) or CAPTCHA triggers to mitigate brute force.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "consecutive_attempts"]`
- **Remediation**: Implement IP and account-based rate limiting (HTTP 429) and account lockout/CAPTCHA after failed attempts.

## Category C — Injection (C023–C036)

### C023: SQL Injection
- **Category**: `INJECTION` | **Severity**: `CRITICAL` | **CWE**: CWE-89 | **OWASP**: A03:2021-Injection
- **Security Property**: User parameters must be parameterized and not concatenated directly into SQL execution contexts.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "sql_error_signature"]`
- **Remediation**: Use parameterized queries (prepared statements) or ORMs for all database operations.

### C024: Blind SQL Injection
- **Category**: `INJECTION` | **Severity**: `CRITICAL` | **CWE**: CWE-89 | **OWASP**: A03:2021-Injection
- **Security Property**: Boolean conditions injected into parameters must not alter SQL execution logic or produce differential responses.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "differential_proof"]`
- **Remediation**: Use parameterized queries across all database drivers and avoid dynamic query concatenation.

### C025: NoSQL Injection
- **Category**: `INJECTION` | **Severity**: `CRITICAL` | **CWE**: CWE-943 | **OWASP**: A03:2021-Injection
- **Security Property**: Document database queries must validate parameter types and reject unsanitized query operator structures.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "nosql_operator_payload"]`
- **Remediation**: Sanitize input object keys and cast query parameters to expected primitive types (e.g. mongo-sanitize).

### C026: Command Injection Indicators
- **Category**: `INJECTION` | **Severity**: `CRITICAL` | **CWE**: CWE-78 | **OWASP**: A03:2021-Injection
- **Security Property**: System shell execution functions must never evaluate unsanitized user inputs or shell delimiters.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "command_error_signature"]`
- **Remediation**: Avoid executing OS commands through shell wrappers; use parameterized process APIs without shell invocation.

### C027: OS Command Injection
- **Category**: `INJECTION` | **Severity**: `CRITICAL` | **CWE**: CWE-78 | **OWASP**: A03:2021-Injection
- **Security Property**: Parameters must not be executed or evaluated in an operating system subshell.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "evaluated_canary"]`
- **Remediation**: Disallow execution of OS commands from web input and use native language APIs.

### C028: Server-Side Template Injection (SSTI)
- **Category**: `INJECTION` | **Severity**: `CRITICAL` | **CWE**: CWE-1336 | **OWASP**: A03:2021-Injection
- **Security Property**: User input must never be evaluated dynamically as raw template engine code.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "evaluated_expression"]`
- **Remediation**: Pass user input strictly as data parameters to templates rather than concatenating user input into template strings.

### C029: Header Injection
- **Category**: `INJECTION` | **Severity**: `HIGH` | **CWE**: CWE-113 | **OWASP**: A03:2021-Injection
- **Security Property**: Header values set by the server must strip carriage return and line feed characters and never accept arbitrary header keys.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "injected_header"]`
- **Remediation**: Sanitize and strip CR (\r) and LF (\n) control characters from any parameter before setting HTTP response headers.

### C030: CRLF Injection / HTTP Response Splitting
- **Category**: `INJECTION` | **Severity**: `HIGH` | **CWE**: CWE-113 | **OWASP**: A03:2021-Injection
- **Security Property**: HTTP response headers must reject carriage return and newline characters to prevent response splitting.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "injected_cookie"]`
- **Remediation**: Disallow or percent-encode CR and LF characters in all parameter values before incorporating into redirects or response headers.

### C031: Path Traversal
- **Category**: `INJECTION` | **Severity**: `HIGH` | **CWE**: CWE-22 | **OWASP**: A01:2021-Broken Access Control
- **Security Property**: File path parameters must be sanitized and constrained strictly to an authorized base directory.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "file_marker"]`
- **Remediation**: Use secure path resolution APIs (e.g. `Path.resolve()`) to verify the canonical path resides within the intended base directory.

### C032: Local File Inclusion (LFI) Indicators
- **Category**: `INJECTION` | **Severity**: `HIGH` | **CWE**: CWE-98 | **OWASP**: A03:2021-Injection
- **Security Property**: File inclusion mechanisms must only include static, pre-whitelisted internal view files.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "decoded_source_snippet"]`
- **Remediation**: Do not pass user-supplied file names directly into include/require directives; map input keys to an explicit allowlist.

### C033: XML External Entity (XXE) Indicators
- **Category**: `INJECTION` | **Severity**: `HIGH` | **CWE**: CWE-611 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: XML parsers must disable DTD processing and external entity resolution.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "expanded_entity_canary"]`
- **Remediation**: Disable external DTDs and entity parsing across all XML parsers (`disallow-doctype-decl = true`).

### C034: LDAP Injection Indicators
- **Category**: `INJECTION` | **Severity**: `HIGH` | **CWE**: CWE-90 | **OWASP**: A03:2021-Injection
- **Security Property**: User parameters concatenated into LDAP search filters must properly escape LDAP metacharacters.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "ldap_error_snippet"]`
- **Remediation**: Use framework-provided LDAP filter encoding functions or parameterized directory search APIs.

### C035: Expression Language (EL) Injection
- **Category**: `INJECTION` | **Severity**: `CRITICAL` | **CWE**: CWE-917 | **OWASP**: A03:2021-Injection
- **Security Property**: User parameters must never be evaluated dynamically within Java Expression Language interpreters.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "evaluated_expression"]`
- **Remediation**: Do not evaluate untrusted user input with SpEL or OGNL parser contexts, and disable dynamic expression evaluation.

### C036: Server-Side Request Forgery (SSRF) Indicators
- **Category**: `INJECTION` | **Severity**: `HIGH` | **CWE**: CWE-918 | **OWASP**: A10:2021-Server-Side Request Forgery
- **Security Property**: Server-side URL fetching must strictly validate destinations against an allowlist and block private IP ranges.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "fetched_resource"]`
- **Remediation**: Enforce an allowlist of permitted destination domains, disable redirects, and block requests resolving to loopback or RFC-1918 private IPs.

## Category D — Cross-Site Scripting (C037–C046)

### C037: Reflected XSS
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: User parameters reflected in HTTP response bodies must be contextually encoded (HTML entity encoded).
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "reflected_canary"]`
- **Remediation**: HTML-encode all user-supplied data before reflecting it in HTML contexts, and adopt a strict CSP.

### C038: Stored XSS Verification
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: Persisted data rendered to clients must be HTML-encoded or sanitized with an established HTML sanitizer.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "persisted_canary"]`
- **Remediation**: Sanitize stored rich text using a hardened sanitizer (e.g. DOMPurify) and contextual output encoding.

### C039: DOM XSS Indicators
- **Category**: `XSS` | **Severity**: `MEDIUM` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: Client-side JavaScript must sanitize DOM sources before writing to execution or HTML sinks.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "sink_source_pattern"]`
- **Remediation**: Use safe DOM properties like textContent instead of innerHTML, or sanitize sources with DOMPurify.

### C040: HTML Context Injection
- **Category**: `XSS` | **Severity**: `MEDIUM` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: User data reflected inside HTML element bodies must be HTML entity encoded.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "injected_tag"]`
- **Remediation**: Apply context-aware HTML entity encoding to user data placed in HTML body content.

### C041: Attribute Context Injection
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: User parameters placed within HTML attribute values must encode quotation marks.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "injected_attribute"]`
- **Remediation**: Attribute-encode all user input placed inside tag attributes (converting quotes to `&quot;` / `&#39;`).

### C042: JavaScript Context Injection
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: User data embedded in JavaScript blocks must be encoded using JavaScript hexadecimal encoding (\xHH / \uHHHH).
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "injected_script_breakout"]`
- **Remediation**: JavaScript-encode all user input placed inside script blocks or serialize data securely using JSON.

### C043: URL Context Injection
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: URL attributes must validate destination schemes and reject `javascript:`, `data:`, and `vbscript:` URIs.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "injected_scheme"]`
- **Remediation**: Validate and enforce an explicit allowlist of URL protocols (http, https) before rendering user URLs into href or src attributes.

### C044: Mutation-Based XSS (mXSS) Indicators
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: HTML sanitization libraries must guard against namespace confusion mutations in MathML and SVG contexts.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "mxss_payload"]`
- **Remediation**: Use up-to-date DOMPurify sanitization with strict MathML/SVG namespace enforcement.

### C045: XSS Filter / Sanitization Bypass Indicators
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: HTML input filters must not rely on case-sensitive string matching or single-pass regex replacement.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "bypassed_payload"]`
- **Remediation**: Replace custom regex/blacklist filtering with established context-aware HTML entity encoders or DOMPurify.

### C046: Unsafe HTML Rendering
- **Category**: `XSS` | **Severity**: `HIGH` | **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Security Property**: Markdown and rich-text renderers must escape or sanitize embedded raw HTML tags.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "rendered_html_tag"]`
- **Remediation**: Configure Markdown renderers to escape HTML or post-process rendered HTML with DOMPurify.

## Category E — Misconfiguration (C047–C056)

### C047: Missing Content Security Policy (CSP)
- **Category**: `MISCONFIG` | **Severity**: `MEDIUM` | **CWE**: CWE-1021 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: HTML endpoints must supply a Content-Security-Policy header restricting script and object sources.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "headers_analyzed"]`
- **Remediation**: Implement a Content-Security-Policy header specifying trusted sources for scripts, styles, and framing.

### C048: Weak Content Security Policy (CSP)
- **Category**: `MISCONFIG` | **Severity**: `LOW` | **CWE**: CWE-1021 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Content Security Policy must not declare unsafe-inline or wildcard sources in script execution contexts.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "csp_header"]`
- **Remediation**: Refactor inline scripts to external files with cryptographic nonces (nonce-...) and remove `unsafe-inline`.

### C049: Clickjacking / Missing Frame Options
- **Category**: `MISCONFIG` | **Severity**: `MEDIUM` | **CWE**: CWE-1021 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: HTML pages must enforce framing restrictions using X-Frame-Options or frame-ancestors.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "framing_headers"]`
- **Remediation**: Send `X-Frame-Options: DENY` (or `SAMEORIGIN`) or include `frame-ancestors 'self'` in CSP.

### C050: MIME Sniffing Vulnerability
- **Category**: `MISCONFIG` | **Severity**: `LOW` | **CWE**: CWE-116 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: All HTTP responses must declare `X-Content-Type-Options: nosniff` to disable MIME sniffing.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "headers_analyzed"]`
- **Remediation**: Add the `X-Content-Type-Options: nosniff` header to all server responses.

### C051: Cross-Domain Policy Misconfiguration
- **Category**: `MISCONFIG` | **Severity**: `LOW` | **CWE**: CWE-942 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Cross-domain policy files must not grant wildcard access to untrusted domains.
- **Verification Strategy**: `generic_reproducibility`
- **Required Evidence**: `["affected_url", "proof_response", "policy_content"]`
- **Remediation**: Restrict crossdomain.xml domain origins to specific trusted domains or remove legacy policy files entirely.

### C052: Insecure HTTP Methods Enabled
- **Category**: `MISCONFIG` | **Severity**: `LOW` | **CWE**: CWE-749 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Web servers must disable TRACE, TRACK, and unauthenticated arbitrary HTTP verbs.
- **Verification Strategy**: `http_response_property`
- **Required Evidence**: `["affected_url", "proof_response", "enabled_methods"]`
- **Remediation**: Disable TRACE and TRACK methods in web server configuration (`TraceEnable Off` in Apache).

### C053: Default / Installation Setup Page Exposed
- **Category**: `MISCONFIG` | **Severity**: `HIGH` | **CWE**: CWE-1188 | **OWASP**: A05:2021-Security Misconfiguration
- **Security Property**: Installation scripts and diagnostic pages must be removed or disabled after initial deployment.
- **Verification Strategy**: `sensitive_file_exposure`
- **Required Evidence**: `["affected_url", "proof_response", "setup_page_indicator"]`
