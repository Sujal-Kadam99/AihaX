# AI training

Material for people and coding agents (Claude Code, Codex, Gemini and similar) that work on this repo.

| File | What it covers |
|---|---|
| [AI_WORKFLOW_GUIDE.md](AI_WORKFLOW_GUIDE.md) | Basic habits for working with AI coding agents: rules file, small steps, proof of work, tooling, safety |
| [JUDGEMENT_REPORT.md](JUDGEMENT_REPORT.md) | Review of the codebase: what is good, what is broken, why, and the design-system problems |
| [FIXES.md](FIXES.md) | Prioritised fix list that follows from the review, with file paths and effort tags |

This folder holds documentation only. It is not a Python package and nothing imports from it.
