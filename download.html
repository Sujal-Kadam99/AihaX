Install and launch AiHaX

windows
linux
macos
1

Download the Windows app bundle

Click the download button above, extract AiHaX-win-unpacked.zip, then run AiHaX.exe from the extracted folder.

2

Install Docker Desktop

AiHaX requires Docker Desktop. If Docker is already installed, skip this step.

3

Launch AiHaX

On first open, the app provisions the backend containers automatically and waits for the FastAPI health check.

4

Add your API key

Go to Settings and configure your Claude API key. The key is stored locally and encrypted.

Install Docker

Install Docker Engine if it is not already available.

curl -fsSL https://get.docker.com | sh

Run the app

The app starts the backend containers automatically on first launch.

4

Configure API keys

Download the DMG

Install Docker Desktop

3

Allow first launch

4

Add your Claude API key

Configure the API key in Settings after the app starts.

before you install

System requirements

RequirementWhy it matters
DockerBackend services run in containers: FastAPI, Redis, and ChromaDB.
64-bit OSAiHaX packages are built for modern 64-bit desktops.
Network accessThe app needs outbound access for updates and AI API requests.
Claude API keyRequired for remediation and business impact agents.

Windows

Requires Windows 10/11 and Docker Desktop. If Docker is installed, AiHaX launches the backend automatically.

Linux

Supports AppImage and .deb packaging. Docker Engine must be installed and running before launching.
